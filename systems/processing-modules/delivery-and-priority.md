## Chrystal Moon Base — Processing Module Logistics

## The Ideal Scenario

All processing modules arrive together on a single delivery mission. They are
compact — the smallest and simplest unit capable of their function. Robots move
them from the landing site to their operational positions, and production begins
in parallel.

This is the ideal. Whether it is achievable depends on module mass and volume,
delivery-vehicle capacity, and whether simultaneous deployment is operationally
manageable. Engineering analysis will determine the actual delivery scenario.

---

## Priority Rationale

No humans arrive until the base is built. Therefore:

**The sintered floor comes first.** Before any processing module operates, the
robot fleet sinters local **anorthosite regolith** directly into a load-bearing
floor (this is a robot task, not a module — see the sintering documents).
Everything else is placed on it.

**Glass and aluminium come first among the modules** — you cannot build domes
without glass, and the dome reinforcement metal is **aluminium**, which highland
anorthosite supplies in abundance (~27 % Al₂O₃). No dome = no pressurised
habitat = no human habitation.

**Life-support gases come second** — oxygen, water, and nitrogen must be ready
before the first humans arrive, but the domes must exist before they can be
filled. Water depends on confirming local polar ice.

**Everything else follows** — silicon, cement, iron, fuel, advanced
manufacturing, and helium-3 expand what the base can do rather than being
prerequisites for habitation.

**Titanium is not on the local critical path.** Its ore (ilmenite) is a mare
mineral, effectively absent at highland Peary. It is treated as an import or a
long-term option, not an early ISRU product.

## Module Sizing Constraint

The maximum size of any module is set by the delivery-vehicle payload fairing and
the underground tunnel dimensions. The Falcon Heavy fairing inner diameter is
approximately 5.2 m. Tunnel dimensions must accommodate the largest module that
will ever need to be moved underground.

Modules should fit within a 2 × 2 × 4 m envelope where possible — small enough
to be carried by 4–6 robots cooperatively and to pass through standard tunnels.
If a module exceeds this size, it is delivered as components and assembled by
robots on the surface or underground.

## Connection Standards

All modules use the same interface standards for:
- **Power:** High-voltage DC bus connection (voltage TBD)
- **Data:** Optical-fibre data link, standard protocol
- **Feedstock:** Standardised pipe flanges for bulk material input
- **Product:** Standardised output interface matching the underground
  distribution system

These standards will be published in a separate interface document
(`INTERFACE-STANDARDS.md` — to be written).
