## Acknowledgements

This project builds on the published work of hundreds of scientists and engineers whose research made these concepts possible to think about. Key references are cited within individual documents. The full list of referenced works would be longer than this repository.

The open-source software community — particularly the Linux project — provided the model for how this repository is organised. The ISS partnership provided the model for how the governance is conceived. CERN provided the model for what international scientific cooperation can achieve.
