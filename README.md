# Chrystal Moon Base

Official open-source repository for the Chrystal Moon Base project — a concept for building a permanent lunar settlement using in-situ resources and autonomous systems.

Status: Phase 0 — Earth demonstrators (concept & planning)

License: See LICENSE, LICENSE-SOFTWARE.md, and LICENSE-HARDWARE.md at the repository root.

Short description
- Autonomous hexapod robots (CMB-R1)
- In-situ laser sintering and local material processing
- Multi-layer titanium-reinforced domes and maglev transport
